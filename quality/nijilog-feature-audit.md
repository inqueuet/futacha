# にじろぐ(仮) 1.1.4との機能比較

対象: `sample/ふたば@アプリ+にじろぐ(仮)_1.1.4_APKPure.apk`。
SHA-256: `94b0dd7546b0d2a6bb7a81ea5b2f94a664825d6c90d17e2a6e20dd8409046362`。
Manifest・リソース・JADX展開ソースによる静的調査。外部APKの全画面を実機で比較した結果ではない。

## Futachaへの追加

互換モードのドロワー → 巡回結果 → 巡回管理から利用する。外部アプリは不要。

| にじろぐの機能 | Futachaの対応 |
| --- | --- |
| 板の追加・編集・削除・並べ替え | 既存の板管理を使用 |
| 板別キーワード、編集・削除・有効/無効・順序変更 | `CompatWatcherManager`、`CompatWatchRule`で追加。全板共通ルールも可能 |
| カタログタイトルのNFKC正規化・大文字化・部分一致 | `CompatWatchText`、`collectCompatWatchMatches` |
| 自動巡回、Wi-Fi限定 | 既存のforeground / WorkManager / BGTaskへ板別ルールと実行ポリシーを接続 |
| 新着通知、通知音・振動 | 通知ON/OFFと権限要求を追加。音・振動はOSの通知設定へ委譲 |
| 巡回ログ（タイトル、板、レス数、画像、一致語、時刻） | 履歴と独立した`CompatWatcherRepository`。URLで重複を防ぎ、初回検出時刻を保持 |
| 結果の個別・全削除 | 巡回ログのみ削除。閲覧履歴や保存スレを削除しない |
| 7日超の結果削除 | 初回検出から7日超で整理。メモリ・保存量を最大500件へ制限 |
| 生存確認 | カタログに存在する結果は生存、見つからない結果は別途確認。404/410だけ落とし、通信失敗は維持 |
| 結果からスレを開く | 既存のスレ表示へ接続 |
| 色・キャッシュ上限・キャッシュ削除 | 既存の共通設定を使用 |
| 外部ブラウザとの連携 | Androidの既存ContentProvider連携を「外部にじろぐの結果を表示」で選択可能 |

既存の全板共通監視ワードは、板別ルール未保存時に引き継ぐ。板別ルールは監視ワード/NGバックアップへ含める。

## 実装上の相違と確認範囲

- 自動実行の正確な時刻はOSに依存する。古いAPKのAlarm/Serviceの周期をそのまま再現せず、既存のOS対応スケジューラを使用する。
- 手動の「今すぐ巡回」は自動巡回OFFやWi-Fi限定設定とは独立し、現在の回線で実行する。手動巡回は画面上で新着件数を通知する。
- 元APKの`strIgnore`は抽出処理で使用されていないため、未実装の除外機能をあるものとして追加しない。
- 外部APKの作者SNSなど固有の導線は複製しない。Futacha自身の既存案内を使用する。
- `CompatWatcherRepositoryTest`でルール移行・板範囲・無効化・回線条件・独立削除・重複・期限・上限・競合・落判定・キャンセル・正規化・バックアップを検証する。
- Android計測テストで空一覧からの管理画面/登録経路、ドロワー復帰、履歴との分離、SQLite再読み込みを検証する。iOSは共有ロジックに加えてNativeコンパイルを確認し、実機のBGTask実行時刻や通知の到達は別途確認対象とする。
